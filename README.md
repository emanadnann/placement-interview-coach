## ✨ How it works

| 1️⃣ Load the AI | 2️⃣ Get a question | 3️⃣ Write your answer | 4️⃣ Get feedback |
|:---:|:---:|:---:|:---:|
| Pick an open-weight model. It downloads once and runs on your device. | Choose a role type and get a realistic interview question. | Answer in your own words, using STAR. | Get a score, a STAR check and a stronger answer.|

## 📋 What feedback you get

| | |
|---|---|
| 🔢 **Score out of 10** | Based on structure, clarity and impact |
| ⭐ **STAR check** | Shows if your Situation, Task, Action and Result are clear or missing |
| 💪 **Stronger version** | A better version of *your* answer to learn from |
| 💬 **Follow-up question** | What an interviewer might ask you next |

## 🚀 Features

- 🔒 **100% private:** the AI runs in your browser with WebGPU, so your answers never go to a server
- 🆓 **Free:** no sign-up, no API key, no backend
- 🧠 **Open-weight models:** Qwen 2.5 (3B or 1.5B) and Gemma 2 (2B)
- 🎯 **Role types:** Software Engineering, Data & Analytics, IT / Digital, and part-time student jobs

## 💡 Why I built it

Placement interviews are stressful, and most students never get honest feedback before the real thing. I wanted a **free coach anyone can use** that keeps answers **private**.

## 🛠️ Tech stack

| Part | Tools |
|---|---|
| **Front end** | HTML, CSS, JavaScript (no framework) |
| **AI in the browser** | [WebLLM](https://github.com/mlc-ai/web-llm) + WebGPU |
| **Models** | Qwen2.5-3B-Instruct · Qwen2.5-1.5B-Instruct · Gemma-2-2B-it (4-bit) |
| **Hosting** | Hugging Face Spaces |

## ▶️ Run it

> 💻 Use **Chrome or Edge on a laptop** (WebGPU is needed). The first load downloads the model (about 1–2 GB), and then your browser saves it.

**Online:** [open the live app](https://huggingface.co/spaces/EmanAdnan/placement-interview-coach)

**On your computer:**

```bash
git clone https://github.com/emanadnann/placement-interview-coach.git
cd placement-interview-coach
python3 -m http.server 8000
```

Then open **http://localhost:8000** in Chrome.
